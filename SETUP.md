# Push to GitHub

1. Create an empty repo named `dsa-python` on github.com (no README).
2. In this folder run:

```
git init
git add .
git commit -m "Initial DSA repo structure"
git branch -M main
git remote add origin https://github.com/<your-username>/dsa-python.git
git push -u origin main
```

3. After each problem:

```
git add .
git commit -m "Add Two Sum (hashmap)"
git push
```

4. Pin the repo on your GitHub profile and add the link to your resume.
